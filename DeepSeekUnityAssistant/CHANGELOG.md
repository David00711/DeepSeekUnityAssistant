## [2.0.0] — 2026-10-11

Крупное обновление: **+26 инструментов**, работа с выделением, префабами, пакетные операции, уборка проекта, скриншоты, Undo-транзакции, макросы.

### Добавлено — Инструменты (всего 49)

**Сцена (6):**
- `inspect_scene` — список корневых объектов с компонентами
- `create_gameobject` — создание примитива (cube/sphere/cylinder/capsule/plane/empty)
- `delete_gameobject` — удаление по имени
- `set_transform` — позиция / поворот / масштаб
- `inspect_object` — детальная информация об объекте
- `list_root_objects` — быстрый список корневых объектов

**Скрипты (2):**
- `read_script` — чтение `.cs` файла
- `create_script` — создание нового скрипта

**Ассеты (1):**
- `find_assets` — поиск по имени и типу

**Материалы и компоненты (6):**
- `create_material` — создать материал Standard с цветом
- `assign_material` — назначить материал объекту
- `add_component` — добавить компонент по имени типа
- `remove_component` — удалить компонент
- `create_prefab` — сохранить объект как префаб
- `set_light` — настройка источника света

**Рельеф и спавн (8):**
- `move_asset` — переместить/переименовать ассет
- `duplicate_object` — копия объекта
- `align_to_ground` — прижать объект к поверхности
- `terrain_get_height` — высота рельефа в точке
- `terrain_place_on_surface` — поместить объект на рельеф
- `scatter_objects` — рассыпать N копий по площади
- `spawn_loot_on_terrain` — рассыпать префабы лута
- `list_terrains` — список загруженных Terrains

**Выделение (6):**
- `get_selection` — список выделенных объектов
- `align_selection_to_ground` — прижать всё выделенное
- `delete_selection` — удалить выделенное
- `duplicate_selection` — дублировать выделенное
- `add_component_to_selection` — компонент на всё выделенное
- `align_all_to_ground` — прижать все корневые объекты сцены

**Префабы (5):**
- `find_prefab_instances` — найти инстансы префаба в сцене
- `open_prefab` — открыть в Prefab Mode
- `apply_prefab_overrides` — применить оверрайды
- `revert_prefab_overrides` — откатить оверрайды
- `unpack_prefab` — распаковать инстанс

**Пакетные операции (5):**
- `batch_rename` — массовое переименование ассетов
- `batch_texture_import` — изменить настройки импорта текстур
- `batch_change_shader` — сменить шейдер у материалов
- `find_duplicate_materials` — найти дубликаты материалов
- `find_assets_in_folder` — список ассетов в папке

**Уборка проекта (9):**
- `analyze_project` — общий отчёт по проекту
- `find_empty_folders` — найти (и опционально удалить) пустые папки
- `find_missing_scripts` — найти Missing Scripts
- `find_duplicate_files` — найти дубликаты файлов по MD5
- `find_same_name_assets` — ассеты с одинаковыми именами
- `find_large_files` — самые тяжёлые файлы
- `find_temp_files` — временные / мусорные файлы
- `find_files_outside_assets` — файлы вне папки `Assets/`
- `delete_asset` — удалить ассет (требует `confirm=true`)

### Добавлено — Интерфейс

- **Стриминг ответов (SSE)** — текст печатается в реальном времени
- **Кнопка Stop** — мгновенный обрыв генерации
- **Копирование текста:**
  - выделение мышью как в обычном поле ввода
  - `Ctrl+C` / `Ctrl+A` — нативное копирование / выделение
  - кнопка **C** у каждого сообщения — копировать целиком
  - `Ctrl+Shift+C` — копировать весь диалог
  - правый клик → контекстное меню (4 опции)
- **📷 Скриншот** — Scene View / Game View в PNG
- **↶ Undo AI** — откат последнего запроса одной кнопкой
- **Macros ▾** — выпадающее меню с сохранёнными промптами
- **Индикаторы в шапке:** `Model`, `Tools`, `Msgs`
- **Автосохранение истории** после каждого ответа
- **Автозагрузка истории** при открытии окна
- **Счётчик символов стрима** под полем ввода

### Добавлено — Функции

- **Undo-транзакции** — все изменения за один запрос склеиваются в одну Undo-группу
- **Макросы** — файл `DeepSeekMacros.asset` с 6 дефолтными макросами
- **Конфиг** — `DeepSeekConfig.asset` с полным набором настроек
- **Setup Wizard** — пошаговая настройка первого запуска
- **История диалога** — сохранение в `Library/DeepSeek/history.json`
- **Автозапуск Setup Wizard** при первом импорте пакета

### Изменено

- **Namespace** — `DeepSeekUnity.*`
- **Автор** — Галавинов Давид Викторович
- **Модель по умолчанию** — `deepseek-chat` (V3)
- **Базовый URL** — `https://api.deepseek.com`
- **Провайдер** — только `OpenAICompatible`, заточенный под DeepSeek

### Исправлено

- **UTF-8** — русский текст в запросах и ответах больше не ломается (`D��D,D1`)
- **SSE-стриминг** — корректный парсинг чанков, двойная буферизация для резки многобайтных символов
- **Tool Calls в стриме** — инкрементальное накопление `arguments` по индексу
- **GUI Layout** — устранено `Invalid GUILayout state` при стриминге
- **Утечка UnityWebRequest** при отмене запроса
- **Ошибка 401** — теперь понятное сообщение вместо сырого JSON
- **Ошибка 402** — «пополни баланс DeepSeek»
- **Ошибка 429** — «слишком много запросов, подожди»

### Удалено

- Поддержка всех провайдеров кроме DeepSeek
- MCP-сервер (перенесён в roadmap)
- Режим `deepseek-reasoner` по умолчанию (оставлен как опция)

## [1.0.0] — 2026-10-11

Первый публичный релиз.

### Добавлено

- Ассистент на базе DeepSeek с поддержкой русского языка
- 23 инструмента: сцена (6), скрипты (2), ассеты (1), материалы (6), рельеф (8)
- Setup Wizard — мастер первого запуска
- SSE-стриминг с кнопкой Stop
- Сохранение истории диалогов в `Library/DeepSeek/history.json`
- Автосохранение после каждого ответа
- Понятные сообщения об ошибках HTTP
- Файл конфига `DeepSeekConfig.asset`
- Автозапуск Setup Wizard при импорте

### Исправлено

- Проблема с кодировкой UTF-8 (кириллица)
- Двойной парсинг SSE-чанков в стриминге
- Утечка `UnityWebRequest` при отмене запроса

### Известные ограничения

- Стриминг не работает на WebGL
- Нет поддержки вложений (изображений)
- Одна сессия на пользователя
- Максимум 8 шагов в agent loop
